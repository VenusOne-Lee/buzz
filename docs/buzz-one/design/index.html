Phase 02 · Decisions & evidence

Steer in one click. Trust becomes inspectable.

A decision is a compact card in the timeline — allow once, allow for the mission, deny, or reply — bound to the exact proposed action. When work completes it posts evidence, not just prose: sources, screenshots, changed files, and a concise rationale.

Design system · Team Table

One warm surface, one green accent,
one loud action in view.

The Team Table language is deliberately narrow so agent work stays legible. A single warm off-white ground, ink text, forest green for every act of collaboration, and orange reserved strictly for consequence. It commits to one light theme on purpose — no dark-mode variant for this initial channel experience.

Principles
▪
Agents are teammates, not a dashboard. People-shaped rows with an AI marker, presence, and readable state — never a separate fleet console.
▪
The channel is always home. Rich agent work lives as an attachment beneath the message that introduced it; the right pane is a true thread that can become Agent at work.
▪
Orange means consequence. The forest accent carries all routine collaboration; orange appears only for action with material or irreversible risk.

Roadmap · ten increments

Ship the conversation-first loop first.

Increments 1–4 make Buzz One visibly different with minimal new infrastructure. Ship evidence and routines next to make work explainable and recurring; build connectors and Computer Session as guarded capability platforms; finish with model profiles and the operator layer.
